3.1

人体的神经系统组成

核心结构图

  • 中枢神经系统： 脑（大脑、小脑、脑干）和 脊髓。
  • 周围神经系统： 脑神经（12对）和 脊神经（31对）。

神经元 (Neuron)

神经系统的基本结构和功能单位。由细胞体和突起（轴突、树突）组成。功能：接受刺激、产生兴奋、传导兴奋。

脑的功能

  • 大脑：智力中枢、感觉、语言、运动。
  • 小脑：协调肌肉运动，维持身体平衡。
  • 脑干：呼吸、心跳等生命中枢。
3.2

人体的神经信息如何传递

反射与反射弧

反射是神经调节的基本方式。结构基础是反射弧。

感受器 → 传入神经 → 神经中枢 → 传出神经 → 效应器

非条件反射

生来就有，低级中枢（脊髓或脑干）参与。如：缩手反射、膝跳反射、吸吮反射。

条件反射

后天获得，需大脑皮层参与。如：望梅止渴、谈虎色变、听到铃声进教室。

3.4

内环境的稳定与调节

内环境：细胞外液（血浆、组织液、淋巴等）。

体温调节

人是恒温动物。产热主要通过肌肉和肝脏；散热主要通过皮肤（辐射、传导、蒸发）。

水分调节

主要由肾脏完成。抗利尿激素分泌增加时，肾小管对水分重吸收增强，尿量减少。

反馈调节：正反馈 与 负反馈（维持稳定的核心）
