4.1 呼吸系统的组成与结构

一、 呼吸道 (通道)

  • 鼻腔： 鼻毛阻挡灰尘，黏膜温暖、湿润并清洁空气。
  • 咽喉： 气体与食物的共同通道；会厌软骨防止食物误入气管。
  • 气管与支气管： C型软骨支撑，纤毛分泌黏液捕捉细菌形成“痰”。

二、 肺 (核心器官)

气体交换的场所。肺泡是功能单位。

肺泡的结构特点

1. 数量极大，提供了巨大的表面积。
2. 肺泡壁极薄（仅有一层上皮细胞构成）。
3. 外包绕着丰富的毛细血管网和弹性纤维，极易进行气体扩散。

4.2 呼吸运动的原理

一、 肺的通气

呼吸运动实现了肺与外界的气体交换，动力来自呼吸肌的收缩舒张，原理是压强差。

吸气过程：
肋间肌和膈肌收缩 → 膈顶下降 → 胸廓容积增大 → 肺扩张 → 肺内压强小于大气压 → 外界气体进入肺。
呼气过程：
肋间肌和膈肌舒张 → 膈顶上升 → 胸廓容积缩小 → 肺收缩 → 肺内压强大于大气压 → 肺内气体排出。

4.3 呼吸作用

一、 细胞内的化学变化 (Cellular Respiration)

呼吸作用是生物体细胞把有机物氧化分解并产生能量的过程。

葡萄糖 + 氧气 → 二氧化碳 + 水 + 能量
（场所：线粒体）

二、 呼吸运动 vs 呼吸作用

呼吸运动

物理变化。指吸气和呼气动作，可见可控。目的是交换气体（引入氧气，排出二氧化碳）。

呼吸作用

化学变化。细胞内氧化分解过程，不可见不可控。实质是分解有机物，释放能量，目的是为生命活动提供能量。

4.4 体内的气体交换

一、 气体交换的过程

气体交换分为三个关键环节，后两个环节的原理都是扩散作用（气体由高浓度向低浓度一侧自发移动）。

  1. 肺的通气： 外界 ↔ 肺泡（依赖呼吸运动造成的压强差）。
  2. 肺泡内的气体交换： 肺泡 ↔ 血液（依赖扩散作用，氧气进入血液）。
  3. 组织里的气体交换： 血液 ↔ 组织细胞（依赖扩散作用，氧气进入细胞被消耗）。

二、 气体成分的变化

吸入气体 vs 呼出气体

• 氧气： 21% → 16% (显著减少)
• 二氧化碳： 0.03% → 4% (增加约100倍)
• 氮气： 78% → 78% (基本不变)
